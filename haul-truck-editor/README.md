# 矿卡 2.5D 分层编辑器

固定主视角的模块化车辆编辑器。它直接使用用户提供的 1168×380 矿卡原图作为视觉来源，以 SVG 裁切路径把可编辑部件重新组合成独立图层，不再用比例失真的自由旋转 3D 模型替代原图。

## 当前实现

- 原图比例、透视和照片细节保持不变；
- 车斗、上层平台、驾驶室、设备室、前部平台、车架、前部装甲、两部梯子和五个近侧车轮均为独立照片裁切层；
- 已分层部件的原图区域被补全层永久遮盖，正常状态由独立照片层覆盖回去；
- 隐藏、删除或移动部件后，原位置显示车架、车轴、地面或厂房补全层，不会继续残留原部件；
- 远侧五个轮胎在这张原图中完全被遮挡，只保留逻辑 ID，等待其他视角素材；
- 前部细栏杆目前属于组合定位层，界面明确禁用伪拆除，等待精细透明蒙版；
- 支持选择、隐藏、删除、恢复、锁定、复制、移动、缩放、旋转和调整层级；
- 支持替换 PNG / WebP / SVG 透明素材；
- 支持添加帐篷、篝火炉、储物箱、铁棚生活区和自定义透明图片；
- 支持安装面吸附、撤销、重做、本机保存、工程 JSON 导入导出和当前画面 PNG 导出；
- 原 3D 版本保留在 `3d/`，没有混入 2.5D 源码。

## 分层原理

每个照片部件都有独立 SVG 裁切形状、变换和数据对象。基础照片上对应的可拆区域由 reveal patch 覆盖，独立照片层位于其上方：

```text
独立部件照片层（可移动 / 隐藏 / 删除）
补全层（车轴 / 车架 / 地面 / 厂房）
基础参考照片
```

当前补全层是结构化 SVG 近似重建，并非自动生成的高精度图像修复。后续获得透明部件素材或补图后，可通过界面替换素材，也可直接更新 `data/vehicle-25d.json`。

## 目录

```text
haul-truck-editor/
├── index.html                      # 2.5D GitHub Pages 生产入口
├── 3d/index.html                   # 保留的旧 3D 版本入口
├── src-25d/
│   ├── index.html                  # 2.5D 源入口
│   ├── app.js                      # SVG 场景与编辑器逻辑
│   └── styles.css                  # 2.5D 编辑器样式
├── src/                            # 保留的 3D 源码
├── data/
│   ├── vehicle-25d.json            # 图层、裁切路径、安装面和附加设施数据
│   └── vehicle-3d.json             # 旧 3D 数据
├── assets/
│   ├── reference/                  # 用户原始参考图
│   ├── editor-25d/                 # 2.5D 构建文件
│   └── app/                         # 保留的旧 3D 构建文件
├── package.json
└── vite.config.js
```

## 本地运行

```bash
npm install
npm run dev
```

## 生成 GitHub Pages 文件

```bash
npm run build
```

构建结果只更新 `haul-truck-editor/` 内的入口和 `assets/editor-25d/`，所有路径均为相对路径，不引用仓库根站点或 `shelter-map/`。
