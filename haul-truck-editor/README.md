# T284 原图外形改造编辑器

第三个 GitHub Pages 子站点。主入口当前使用真实 Liebherr T284 GLB 作为精细改造底模；旧 2.5D 试验版保留在 `2d/`，不与主编辑器混用。

## 正式比例基准

- 1 个 Three.js 单位 = 1 米；
- 整车目标长度约 24 米，暂定总宽 12.4 米；
- 前维护平台面离地 8.9 米；
- 四轴、左右共 8 个独立轮组，轮径约 4.9 米；
- 轮组使用柔性金属骨架、复合缓冲层与可更换耐磨模块造型；
- 额定载荷 680 吨作为工程元数据记录；
- 斗内水平仓库地板暂定 14.0 × 8.2 米，共 114.8 平方米；
- 车斗仍保持倾斜自卸结构，水平层与倾斜斗底之间为楔形设备／储物空间；
- 一期二层平台长 7 米，使用斗内可用宽度，可继续向后扩建；
- 6 立方米水箱、1.5 立方米冷藏区与 3 立方米冷冻区均为独立对象。

以上数据是后续八轮改造的硬基准，不冒充当前 T284 源模型已经达到这些尺寸和结构。

## 第七版原图外形改造

- 接入 Sketchfab 作者 gelber 发布的 Liebherr T284 GLB；
- 授权为 CC BY 4.0，来源信息保留在 GLB 元数据中；
- 保留源模型的 81 个网格、27 个材质与 13 张内嵌贴图；
- 删除素材自带地面及无关角色，保留一名成年人作为约 2 米尺度参照；
- 按原始语义节点将车架、车头、驾驶室、设备箱、货斗、平台、栏杆、传动与机械细节注册进编辑器；
- 当前源素材仍是六轮结构，而且轮胎／轮毂分别属于合并网格；八轮独立拆分将在确认底模外观后继续完成。

## 可编辑对象

当前可编辑对象包含 T284 源模型的真实网格组，以及依据参考图新增的独立改造模块：超宽前维护甲板、左侧驾驶室、右侧设备室、覆盖式上层斜甲板、左右货斗加高壁、重型前脸、栏杆和登车梯。改造件没有烘焙进原车，可逐件隐藏、拆除或恢复。

人物比例参照同样属于独立图层。轮胎总成和轮毂总成暂时仍为各自合并对象，网页明确标注其状态，不冒充已经完成的八个独立轮组。

支持选择、隐藏、拆除、恢复、锁定、复制、移动、缩放、旋转、安装点吸附、本机保存、撤销／重做，以及 JSON、PNG 和 GLB 导出。新增帐篷、篝火、储物箱、铁棚或外部 GLB／透明图片时，不需要改动车辆本体。

## 目录

```text
haul-truck-editor/
├── index.html                 # 3D 生产入口
├── 3d/index.html              # 与主入口同步的 3D 兼容地址
├── 2d/index.html              # 保留的 2.5D 试验版
├── src/                       # 3D 编辑器源码
├── src-25d/                   # 2.5D 旧版源码
├── data/
│   ├── vehicle-3d.json        # 正式尺寸、部件分类与安装点
│   └── vehicle-25d.json       # 旧版图层数据
├── scripts/audit-model.mjs    # 源模型完整性与接入状态审计
├── source-assets/models/      # 原始 Liebherr T284 GLB
└── assets/                    # 各版本独立构建资源
```

## 本地校验

```bash
npm ci
npm run audit
npm run build
```

构建和数据路径全部使用相对路径，只更新 `haul-truck-editor/`，不引用仓库根站点或 `shelter-map/`。
