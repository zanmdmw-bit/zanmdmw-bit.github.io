# 矿卡 3D 模块化编辑器

参考用户提供的矿山运输车图片制作的浏览器三维编辑器。车辆不是一张带点击热区的背景图，而是由独立 Three.js Mesh 组成的实时模型。

## 当前模型

- 38 个基础可编辑对象；
- 约 1,093 个可渲染网格实例；
- 约 102,000 个三角面；
- 五根独立轮轴、十只独立车轮；
- 独立的承载车架、底部护板、动力模块；
- 独立的左侧驾驶室与右侧设备室；
- 独立的维护平台、上层平台、车斗、车斗前保护板与液压系统；
- 独立的栏杆、梯子、保险杠、格栅、灯组、罐组、排气系统与工具箱；
- 八个附加设施安装点。

默认视图使用原图的五个可见轮心、车斗顶线、双舱位置和车头平台轮廓进行投影校准；五个轮心的校准误差均小于 5 像素。编辑场景采用日光矿区环境，并提供“原图叠加”结构线校验模式。

原图不可见的车尾、车底与另一侧，按同类十轮重型矿卡结构进行合理补全，不宣称是特定厂商的工程级复刻。

## 编辑功能

- 点击画面或部件树选择对象；
- 隐藏、拆除、恢复、锁定与复制；
- 三轴移动、旋转与缩放；
- 恢复对象初始变换；
- 吸附到车体安装点；
- 添加帐篷、篝火炉、储物箱和铁棚生活区；
- 导入 GLB 模型或透明图片；
- 撤销、重做与本机保存；
- 导出当前画面 PNG、车辆 GLB 和工程 JSON。
- 一键切换原图叠加模式，核对模型轮廓和部件比例。

拆除车轮会真实隐藏对应车轮 Mesh，露出后方建模的轮轴与悬挂；拆除车斗会露出承载车架和液压结构。

## 目录

```text
haul-truck-editor/
├── index.html                    # GitHub Pages 生产入口
├── src/
│   ├── index.html                # Vite 源入口
│   ├── app.js                    # 三维场景与编辑逻辑
│   ├── truck-model.js            # 模块化矿卡建模代码
│   └── styles.css                # 编辑器样式
├── data/
│   └── vehicle-3d.json           # 方向、尺寸、分类和安装点数据
├── assets/
│   ├── reference/                # 用户原始参考图
│   └── app/                      # 构建后的独立 CSS、JS 与图片
├── package.json
└── vite.config.js
```

## 本地运行

```bash
npm install
npm run dev
```

## 生成 GitHub Pages 文件

```bash
npm run build
```

构建结果直接更新本目录的 `index.html` 与 `assets/app/`。所有运行时路径均为相对路径，不依赖仓库根站点或 `shelter-map/`。
