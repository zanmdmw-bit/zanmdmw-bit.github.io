# 避难所 RP 地图网页

这是与仓库现有双陆世界网页完全隔离的独立页面。当前页面显示广州市天河公园卫星影像，以及按真实经纬度和米制尺寸生成的现代混凝土防御围墙。

## 地图与三维技术

- 地图库：MapLibre GL JS 6.0.0。
- 三维渲染：MapLibre WebGL `fill-extrusion`，高度和基础高度均以米为单位。
- 卫星底图：Esri World Imagery 栅格瓦片。
- 瓦片端点：`https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}`。
- API Key：当前公开端点不需要密钥。若服务政策变化，只能改用供应商支持的浏览器端受限密钥，且不能向公开仓库提交通用私密密钥。
- 署名：页面右下角保留 MapLibre、Esri 及影像数据提供方署名，不得删除或遮挡。
- 原生瓦片缩放：页面限制为 14—19 级；19 级后不再继续放大，也不承诺超过数据源原生分辨率后继续变清晰。

Esri 服务和署名要求：

- <https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9>
- <https://developers.arcgis.com/documentation/esri-and-data-attribution/interactive-maps/>

## 坐标系统与地图范围

- 配置坐标：WGS-84 `[纬度, 经度]`。
- GeoJSON 坐标：WGS-84 `[经度, 纬度]`。
- 地图投影：EPSG:3857 Web Mercator，由 MapLibre 与卫星瓦片共同处理。
- 围墙几何计算：以围墙节点平均位置为原点建立局部等距近似米制平面，所有厚度、通道宽度、护墙宽度和细部尺寸先按米计算，再转回 WGS-84。没有直接给经纬度加减固定小数。
- 天河公园中心：`23.1304739, 113.3618998`。
- 天河公园边界：西南 `23.1254324, 113.3568309`，东北 `23.1359017, 113.3668616`。
- 最大拖动范围：西南 `23.075, 113.29`，东北 `23.19, 113.44`。

Esri World Imagery、WGS-84 GeoJSON 和 Web Mercator 显示可直接对齐，不需要 GCJ-02 或 BD-09 转换。高德、百度等坐标不能直接混用。

## 围墙范围

`js/wall-config.js` 内的 `wallFootprint` 保存正式节点：

```js
wallFootprint: [
  [23.1323089, 113.3582165],
  [23.1323089, 113.3649835],
  [23.1287381, 113.3649835],
  [23.1287381, 113.3607434],
  [23.1274883, 113.3607434],
  [23.1274883, 113.3589660],
  [23.1287381, 113.3589660],
  [23.1287381, 113.3582165]
]
```

这 8 个转折点由标注图的亮红粗框校准到上一版错误正方形的已知 WGS-84 四角后得到。主区域是横向大矩形，西南偏南位置保留独立矩形凸出部；不再存在旧版 300 米正方形的中心、边长、旋转角、红色填充或尺寸校验逻辑。

## 实体结构

主要参数集中在 `js/wall-config.js`：

```js
wallThicknessMeters: 1.8,
wallHeightMeters: 6.5,
topWalkwayWidthMeters: 1.2,
topGuardHeightMeters: 1.1
```

`wall-geometry.js` 先把中心路径投影到局部米制平面。对每条边求单位切向和内法向，再求相邻偏移直线交点，生成连续的内外边缘和斜接转角。墙体由具有内环的真实带状 Polygon 构成，不是固定像素线。

三维结构分层如下：

- 2.4 米宽、0.35 米高的深灰基础边缘。
- 1.8 米厚、6.5 米高的浅灰混凝土墙身。
- 1.2 米有效宽度的连续墙顶巡逻通道。
- 外侧混凝土胸墙和内侧低护墙，均高出通道约 1.1 米。
- 8 个约 4.2 米宽的轻度加厚转角观察平台。
- 长直墙段上的少量深色观察口和火力口，以贴合外墙面的浅深度矢量体表现。
- 近景可见的少量施工接缝、低位苔污和雨水痕迹。

所有结构都是 GeoJSON 矢量面经过 WebGL 挤出形成。缩放和平移时固定在地理坐标上；俯视时可见实际墙顶厚度，倾斜时可见 6.5 米墙高。

## 视角与分级细节

- 地图默认北向俯视，并完整显示天河公园。
- 左上角保留缩放和罗盘；`3D` 按钮切换到 55° 倾斜视角，`俯`按钮恢复北向俯视。
- 鼠标右键拖动或按住 `Ctrl` 拖动可旋转、倾斜；触屏双指可缩放、旋转和倾斜。
- 14 级显示基础墙体；15.5 级起显示通道；16 级起显示平台；16.5 级起显示护墙；17.25 级起显示观察口和火力口；18 级起显示接缝和污渍。
- 细部数量保持在几十个低面数矢量体内，避免手机端一次渲染过多构件。

## 隐藏编辑模式

正常地址只显示地图、地图控制、三维围墙和法定署名：

<https://zanmdmw-bit.github.io/shelter-map/>

在地址后加 `?editWall=1` 进入开发编辑模式：

<https://zanmdmw-bit.github.io/shelter-map/?editWall=1>

编辑模式会显示 8 个可拖动节点和一条红色辅助中心线。点击节点可选中；“增加节点”会在当前最长墙段的中点插入节点；“删除所选”会删除当前节点；“导出坐标”和“导出 GeoJSON”会把结果写入文本框并复制到剪贴板。

浏览器内编辑不会自动写入 GitHub。确认位置后，应把导出的 `[纬度, 经度]` 数组写回 `js/wall-config.js` 的 `wallFootprint`，再提交部署。当前正式 8 点坐标已经写入配置文件，不依赖浏览器内存。

## 文件结构

```text
shelter-map/
├── index.html
├── css/
│   └── map.css
├── js/
│   ├── map.js
│   ├── bootstrap.js
│   ├── wall-config.js
│   ├── wall-geometry.js
│   ├── wall-renderer.js
│   └── wall-editor.js
└── README.md
```

- `bootstrap.js`：加载 MapLibre ES 模块并依次启动页面模块。
- `map.js`：卫星地图、范围、交互和视角控制。
- `wall-config.js`：节点、尺寸、材质和分级细节参数。
- `wall-geometry.js`：局部米制投影、偏移边缘、带状面、平台和细节几何。
- `wall-renderer.js`：MapLibre 数据源、挤出层、材质与缩放级别。
- `wall-editor.js`：仅在 `editWall=1` 时建立拖动节点、辅助线和导出工具。

全部页面资源使用相对路径，适用于 GitHub Pages 的 `/shelter-map/` 子目录部署。
