等级是世界法则对生命状态的简化记录，不是职业证书，也不是决定胜负的血条。它把身体、灵魂、魔力与已经完成的生命蜕变压缩成一组可读数字，却不会替一个人学会剑术、法术、战术和勇气。

所以，一名十级士兵可能凭借队形、长枪和同伴杀死更高等级的野兽；一名属性惊人的贵族也可能因为从未见过真正战场，在第一次伏击中死去。等级能够说明生命抵达了什么层次，不能脱离现实条件单独说明“谁一定赢”。

## 等级不是职业

本世界不存在战士、盗贼、法师职业栏，也没有转职任务、职业专属装备、固定技能树和强制的坦克、输出、治疗分工。“骑士”“刺客”“猎人”“法师”只是训练方向、谋生方式或社会身份。

盗贼可以穿甲持盾，法师可以学习弓术，骑士也能研究治疗术。能否真正使用，取决于有没有老师与知识、身体是否适应、训练是否足够、装备是否适合当前环境。等级提升不会自动赠送技能，面板也不限制武器。

普通本地人看不见别人的精确等级。公会记录、神殿仪式、魔法检测、鉴定道具、讨伐证明、声望和实战表现只能提供估计，因此谎报、隐藏和误判实力都很常见。

## 面板记录什么，又遗漏什么

面板综合反映身体结构、神经反应、灵魂强度、魔力容量、感知能力、生命本质与已经完成的蜕变，现行基础属性共有六项：

| 属性 | 主要代表 | 不会自动提供 |
| --- | --- | --- |
| 力量 | 爆发、挥击、负重、擒抱、投掷与结构破坏 | 命中、速度、战术与法术抗性 |
| 敏捷 | 神经反应、协调、动作转换、短距爆发与武器控制 | 视野、移动空间与对未知攻击的自动闪避 |
| 体质 | 耐力、恢复、抗冲击、抗病、器官与失血承受 | 不死、灵魂防御与对同级致命伤的免疫 |
| 精神 | 注意力、意志稳定、施法控制、灵魂承载与恢复 | 知识、智谋、情商与绝对精神免疫 |
| 魔力 | 魔力容量、输出上限、恢复与法术承载 | 法术知识、咏唱速度和控制精度 |
| 感知 | 视听、危险直觉、追踪、距离与魔力波动判断 | 全知、识破完美伪装与神明级遮蔽 |

面板不会显示剑术熟练度、战术智慧、法术知识、社会地位、装备质量、实战经验、勇气和临场判断。这些被遗漏的东西，往往正是同等级者之间决定生死的部分。

## 属性与升级

普通健康成年人的单项属性通常为 **8—12点**，10点可视作平均水平。每次升级，力量、敏捷、体质、精神、魔力与感知六项基础属性全部增加1点，并获得5点可自由分配的属性。自由点只能强化这六项基础属性，不能直接兑换知识、技能、法术、武器熟练度、战斗经验、语言或专业技术。

| 属性值 | 大致生命层次 |
| --- | --- |
| 10 | 普通成年人 |
| 15 | 训练良好的士兵或猎人 |
| 20 | 普通人类自然极限附近 |
| 30 | 明显超出凡人 |
| 50 | 低阶超凡身体 |
| 100 | 对普通人形成绝对属性压制 |
| 200 | 英雄级怪物或顶级强者 |
| 500以上 | 传奇、神话或神权核心领域 |

单项属性达到30点，只表示该项能力已经明显超出普通人极限，不等于整体生命进入超凡阶。真正的超凡生命需要身体、精神、灵魂、魔力和感知等多方面达到足够承载水平，并完成对应的生命本质突破。

属性不是技能，等级不是职业，等级也不是血条；等级和属性都不等于绝对战斗力。种族、体型、装备、技巧、经验、胆量、伤势、环境、情报、陷阱、毒药、配合与临场判断都会改变胜负。

在普通人范围内，1点属性大约造成8%—12%的实际差异；进入高属性后不能继续按简单百分比叠加，因为增长已经涉及骨骼、肌肉与魔力结合、神经传导、灵魂控制和生命结构的改变。同样是力量100，人类、巨人、古龙、史莱姆和昆虫型魔物的表现也不会相同：属性说明能力，身体结构决定能力怎样释放。

## 经验归属

击杀经验只归最后真正令目标从存活状态变为死亡状态的人，不按累计伤害、控制、治疗、保护或其他团队贡献分配。高等级者可以削弱、压制或控制目标，再由低等级者完成真正的致死攻击；只要死亡尚未发生，带升级就是世界规则允许的行为。

默认不获得击杀经验的行为包括：只造成伤害但未完成最终击杀、控制或压制目标、治疗或强化击杀者、吸引仇恨、提供情报与指挥、借出武器或药物、搬运包围及阻断逃跑路线。攻击已经死亡的尸体不算击杀。同一目标不能多人平分经验，也不能重复结算。

延迟致死手段按实际致死来源判断：毒药归下毒者，陷阱归布置者，诅咒归施加者，持续燃烧或流血归制造该持续效果的人；攻击直接把目标逼落悬崖并导致死亡时归攻击者。若最终死因无法可靠判定，则不产生击杀经验。

## 分阶段的经验来源

**凡人阶（1—20级）**最直接、最稳定的面板经验来源是实际击杀生命体。跑步、力量训练、普通挥剑、射箭练习、读书、学习语言、普通冥想、普通魔力循环、经商、种地、治病、制作物品和交付普通任务不会直接增加面板经验；它们提高的是技巧、知识、熟练度、身体与魔力控制、战斗判断和突破成功率。

**超凡阶及以上（21级以后）**除了击杀，还可以通过真正改变生命本质、超凡结构、灵魂强度、魔力结构或法则掌握程度的修炼缓慢获得面板经验，例如本源淬炼、超凡核心稳定与强化、魔力压缩和质变、精神模型或灵魂结构重构、高阶血脉补全、世界本源吸收、领域建立与完善、权柄与法则理解、神性结构完善以及神格修复、融合或升华。

普通挥剑、跑步、日常冥想、机械重复施法和已经完全掌握的低阶训练仍不能稳定产生面板经验。修炼只有确实推动生命层次、超凡结构或法则掌握时，才可能转化为经验。

高阶血脉觉醒、神明赐福、世界本源吸收、高阶超凡材料融合、神格修复、新权柄掌握、领域建立，以及足以改变地区、国家、种族或世界格局的重大行为，也可能在真正造成生命质变或得到世界法则反馈时提供经验。获得材料、接受祝福或完成普通任务本身不会自动加经验；击杀经验、修炼经验和法则反馈经验必须分别记录来源。

## 可以提供击杀经验的目标

目标必须拥有真实生命或等价生命核心，例如智慧生命、普通动物、魔物、亡灵、恶魔、龙族，以及具有独立意识、灵魂、魔核、意识核心或亡灵本源的构装生命。

普通植物、已经死亡的尸体、幻象、没有独立意识的召唤残影、单纯魔力投影、没有生命核心的机械空壳和不具备独立生命性质的傀儡外壳通常不提供经验。特殊植物生命、独立召唤生命与拥有真实灵魂的构装体，按其是否具备独立生命本质判断。

## 击杀经验公式

普通目标基础经验为 **目标等级×100**。最终击杀经验为：

**目标等级×100×目标强度倍率×等级差倍率。**

| 目标强度 | 倍率 |
| --- | ---: |
| 普通单位 | ×1 |
| 精英单位 | ×3 |
| 首领单位 | ×10 |
| 领主级单位 | ×30 |
| 灾厄级单位 | ×100 |
| 神话级单位 | ×300以上 |

神话级以上的特殊目标可以按实际生命层次单独确定倍率，但不得低于已经确定的最低标准。

| 目标相对击杀者等级 | 等级差倍率 |
| --- | ---: |
| 低10级及以上 | ×0 |
| 低5—9级 | ×10% |
| 低3—4级 | ×30% |
| 低1—2级 | ×70% |
| 同级 | ×100% |
| 高1—2级 | ×150% |
| 高3—5级 | ×250% |
| 高6—10级 | ×500% |
| 高超过10级 | ×1000% |

强度倍率与等级差倍率可以叠加。例如30级角色击杀30级普通目标获得3,000经验，击杀30级首领获得30,000经验，击杀33级普通目标获得8,250经验；击杀20级普通目标时因目标低10级，经验为0。

## 七个生命阶段与突破通则

| 等级 | 阶段 |
| --- | --- |
| Lv.1—20 | 凡人阶 |
| Lv.21—40 | 超凡阶 |
| Lv.41—60 | 英雄阶 |
| Lv.61—80 | 传奇阶 |
| Lv.81—89 | 神话阶 |
| Lv.90—99 | 神祇阶 |
| Lv.100 | 主神阶 |

经验达到要求只代表拥有数值资格。20→21、40→41、60→61、80→81、89→90与99→100还必须完成相应的生命突破；经验不足时，即使拥有材料也不能正常升级。经验已满但突破条件未满足时，停留在当前阶段上限，后续经验按当时已确认的面板口径处理，不擅自增加新的暂存规则。

“超凡核心”“英雄印记”“传奇领域”“神话真身”分别是前四次生命阶段变化的通用概括，不是所有种族与体系唯一且完全相同的功法。不同生命可以采用不同凝聚方式、外观、仪式与能力表现。

### 89级突破90级

89级经验达到15,842,000后仍不能自动成为90级神祇。突破者必须拥有仍可承载神性的残破神格、重构出的神格雏形或等价神性核心，同时让肉体与灵魂能够承受神性结构，并至少形成一种明确的神职、权柄或规则方向，完成从神话生命到神性生命的本质变化。

残破神格只提供突破所需的神性结构，不等于完整神格，也不保证融合成功。原主人的神职、残留意志与记忆可能造成神格反噬、灵魂崩溃、人格污染、记忆混乱、权柄冲突、神性失控、神躯畸变乃至死亡。

进入90级后，生命已完成真正神性转化，应具有神性生命结构、可正常运转的神格或神格雏形，以及至少一种明确的神职、权柄或法则方向。90级不等于拥有完整神格；神祇阶仍可通过击杀、神格修复与碎片融合、权柄感悟、神职完善、神性和神躯强化、神国或信仰体系建设、法则反馈及高阶神性修炼继续成长。只有真正推动神格、神性或权柄的过程才可能提供经验，日常接受信仰与重复仪式不会无限产出经验。

### 99级突破100级

99级经验达到19,602,000后仍不能自动进入主神阶。突破者必须拥有完整、稳定且达到主神层次的神格，完整掌握至少一种核心神职或主要权柄，并使神格、神躯、灵魂、神职与权柄稳定统一，能够独立维持主神级神性结构，不再依赖残破神格、临时仪式或其他神祇持续供能。

普通完整神格未必达到主神层次。修复、升华或重构神格，吞并同源神格、融合神职、掌握核心权柄、取得世界法则认可与建立稳定神性锚点，都可能是实际路径。神国、神座、庞大信仰和世界锚点可以稳定主神力量，但不同神系、种族和成神路线的实现形式不同，不是所有主神完全统一的绝对条件。

神格是承载神性与规则结构的核心，神职是神祇承担或占据的规则职位与职责，权柄是对具体法则的实际支配能力；神国、神座与信仰则是可能的稳定方式和力量来源。它们彼此关联，但不能完全等同。

当前大陆已有九位100级主神。这是现有神系数量，不是世界只能存在九位主神，也不代表所有100级生命会自动成为现有神系成员。

## 时间、寿命与强者稀缺

没有资源与机缘时，21—40级纯修炼升一级常需数年到数十年，41—60级需十年至上百年，61—80级需数十年至数百年，81—89级甚至需要百年至上千年；90级以上不可能仅靠普通修炼。

长生种可以用数百年积累，人类若没有延寿药剂、血脉改变、神术、高阶突破或特殊传承，通常活不到自然修炼至传奇的年龄。延寿也不等于升级：秘药能给君主更多执政和训练时间，却不能凭空提供击杀经验、英雄印记与传奇领域。

大陆、魔界与已知神庭范围内，21—40级约有15万—25万人，41—60级约3,500—5,000人，61—80级约140—200人；81—89级已确认21名，推测不超过40名；神庭承认的90—99级从神与小神约二十余名，100级主神只有九位。完全未知的封印存在不计入统计。

## 高等级怪物为什么仍然存在

文明稳定控制区只占大陆约四成，余下的无人荒野、深层地下城、古代遗迹、魔力灾区、龙族领地、世界边缘、海底深渊、魔界和封印生态区仍有高阶目标。1—10级怪物在城镇附近常见，11—20级多见于危险荒野与小型巢穴，21—40级是深层荒野和地区霸主，41—60级已是区域灾害，61—80级包括古代巨兽、成年龙和高阶魔王眷属，81—89级则是能够影响大陆政治的世界级独立存在。

高级怪物不会像低级魔物一样不断刷新。41级以上通常拥有固定领地与生态地位，61级以上的名字、习性和疆域会被国家长期记录。它们数量稀少、有情报、有族群与盟友，击杀风险接近同归于尽；其材料还会引发国家和组织争夺。因此高阶强者通常是修炼数十年、寻找一次机缘、完成一次突破、冒险击杀一两个同级目标，再继续漫长修炼，而不是每天进森林寻找同级怪物。

## 现实战斗怎样判断

完整战斗力至少由九部分组成：等级、属性分配、种族与身体结构、武器装备、技巧训练、法术战技与血脉能力、距离地形与机动、情报与克制，以及当时的伤势、疲劳和心理状态。

力量高者可能被飞行和远程攻击持续拉开距离；敏捷高者仍可能死于背后弩箭、箭雨、无死角爆炸与狭窄通道；高体质者仍会被斩首、穿脑、毁心、灵魂攻击与同级毒药杀死；高精神者可能被政治欺骗；高魔力者若不会法术，只是拥有大量未被利用的能源；高感知者也无法发现完全陌生且没有外泄的诅咒。

等级相差5级以内，技巧、装备、环境和克制足以改变胜负；相差5—10级，低等级者通常需要偷袭、人数、强力装备、针对性毒药、地形或对手负伤；相差10—20级，正面战斗极不利，但暗杀、封印、陷阱和神器仍可能成功；相差20级以上，普通正面对抗基本没有胜算，只有契约漏洞、神性毒药、世界级法阵和同级神器等手段可能绕开直接属性压制。

## 初代勇者与神庭门槛

初代勇者阿尔德雷恩在黑日战争最终阶段，以点燃神火并凝聚神格雏形完成89→90的神性突破，达到 **90级**。他理论上已经有资格进入神庭，却把神火、神格雏形、大部分力量和自身存在投入九重界锁，没有建立神座。

因此他可能已经死亡，也可能以不完整神祇状态与封印融为一体。九位主神不能轻易收回他的神格，因为那可能令深渊王门重新开启。阿尔德雷恩是极少数已经越过凡世上限，却没有成为神庭正式神祇的存在；他的90级也再次说明，凡人史诗的顶点仍低于100级主神。

## 普通穿越者面板与千叶专属系统

地球穿越者拥有只显示等级、经验和六项属性的基础个人面板；它是世界法则对生命状态的记录，不是千叶的金手指。只有千叶拥有【异世界生存系统】。

系统初始核心功能只有三类：生存指标事后结算、物品回收和系统商城。系统不主动发布强制任务，也不会要求千叶完成指定目标；它只对已经发生并符合条件的生存行为进行结算。

经验与生存点是两套独立机制。同一次击杀可以同时产生二者，但经验按目标等级、目标强度、双方等级差和最终击杀归属计算；生存点按目标对千叶的实际威胁、行为的生存价值、危险程度、稀缺性与是否刻意刷取判断。生存点用于系统商城和系统相关消费，不能当作经验；经验也不能当作生存点。

商城理论上可以搜索任何商品，高级商品主要受价格、身体与知识承载、现实使用条件和暴露风险限制，而不是搜索权限。商城不直接出售等级、经验或自由属性点。系统购买物直接回收时不给生存点或只给极低残值；商品可以在本地出售、交换、抵押或拍卖，本地所得货币与物品也可以正常回收，但时间、运输、渠道、税收、压价、治安、抢劫、识货与身份暴露风险都必须真实存在，不能形成无成本无限刷点循环。

系统能够提供中文说明、跨体系知识、兼容训练方案、装备与其他文明物品，但不能替代实际训练、身体适应、法术控制、情报和临场判断。千叶仍遵守共同的等级、经验、属性和突破规则。

网站隐藏设定把系统暂列为地球迁移工程之外的独立跨界生存终端，但创造者、最终来源和绑定原因仍未确定。这不是千叶开局已知事实，只能出现在未知、推测或作者级隐藏区域，不能作为角色公开认知。
